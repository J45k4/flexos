# Version 0.1

## March 2021 milestone

Plan is to make flexible operating system that is not just runnable on bare metal but also on virtual machines and on top of other operating systems. Basically it means that flexos can be started on top of the existing operating system like linux. When flexos is started on to of existing operating system it should use those resources already available in that platform. This means flexos kernel should be detached from hardware specific things.

### First Milestone

The intention would be to do mvp version that just contains executable software for linux that contains version of kernel and simple console shell for interacting with the kernel.

Description of requirements
- Simple shell having access root access to kernel.
- Console implementation
